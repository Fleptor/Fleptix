Quickstart Deployment

Up and Running in 5 Seconds

Fleptix Observer runs as a single, lightweight container connected to your local Docker socket with zero configuration required. 

# Stop & replace any existing container, then run Fleptix Observer
docker rm -f fleptix-observer 2>/dev/null; docker run -d \
  --name fleptix-observer \
  -p 7373:80 \
  -v /var/run/docker.sock:/var/run/docker.sock \
  -v fleptix-data:/app/snapshots \
  --restart unless-stopped \
  ghcr.io/fleptor/fleptix:latest
Direct Docker socket integration
< 35MB RAM footprint
Access at: http://localhost:7373
