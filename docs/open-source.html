Open Source & Licensing

We believe developer infrastructure tools should be honest, inspectable, and respectful of your data. Here is our clear commitment to open source, privacy, and perpetual licensing.

100% Free & Open Core

Fleptix Observer is licensed under the permissive MIT License. The entire core code—from live telemetry streaming to container shell execution—is open on GitHub for anyone to audit, run, or build upon.

Zero Telemetry Guarantee

Fleptix does not phone home. There are no tracking scripts, no telemetry pings, and no analytics beacons. Your container names, logs, images, and environment variables stay strictly on your host.

Air-Gapped Ready

Because Fleptix communicates exclusively with your local Docker socket via /var/run/docker.sock, it runs seamlessly in isolated, air-gapped, or firewalled private clouds without internet connectivity.

Commercial Use Allowed

You are fully permitted to run Fleptix Observer inside your business, agency, or production infrastructure free of charge under MIT terms. No artificial node caps on the open core.

The Boundary: Observer vs. Time Machine

Sustainable open source requires a clear and honest business model. Instead of hiding behind misleading licenses, artificial limits, or bait-and-switch telemetry, Fleptix draws a clean boundary between two editions:

Fleptix Observer (Open Source • MIT): Everything you need to monitor, manage, and inspect your container fleet in real time. This includes live resource graphs (CPU, RAM, Network, Disk), interactive exec terminal, streaming container logs, Docker Compose grouping, and start/stop/restart controls. We never cripple the core observer.

Fleptix Time Machine (Commercial Pro): An advanced state capture engine designed for teams needing automated container filesystem delta snapshots, point-in-time state rollback, and isolated sandbox replays. Time Machine is distributed under a commercial perpetual license (one-time payment, no recurring monthly tax) to fund full-time development of the open-source core.

Privacy & Data Sovereignty

Many modern DevOps and observability tools quietly ship analytics SDKs, user fingerprinting, or forced cloud accounts. Fleptix was built with the opposite philosophy:

1. No Cloud Accounts Required: You never need to sign up, create an account, or log in to use Fleptix Observer.

2. No Outbound Telemetry: The Observer binary makes no outbound network connections to Fleptix servers. Your server configuration, IP addresses, container images, volume paths, and environment secrets never leave your host.

3. Direct Socket Communication: Communication happens strictly through the local Docker Unix socket (/var/run/docker.sock).
